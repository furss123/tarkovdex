# TarkovDex Maps Image Completion Pack

Purpose:
Fill missing images on the TarkovDex Maps page without replacing images that are already present.

Recommended workflow:
1. Unzip this package in or next to the project.
2. Give `CLAUDE_CODE_MAPS_COMPLETION_PROMPT.md` to Claude Code.
3. Let Claude inspect the repository before it copies assets.
4. The supplied images should be used as fallbacks only.

Notes:
- Night Factory reuses `factory.webp`.
- Ground Zero 21+ (if your data exposes it) reuses `ground-zero.webp`.
- Assets are generic atmosphere images, not official EFT screenshots.
- The live repository's map IDs and current data are the source of truth.
